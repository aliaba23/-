وقتی پکیج ارور می‌دهد چه اطلاعاتی ثبت کنیم؟

کد خطا می‌تواند سرنخی برای عیب‌یابی باشد، اما معنی آن بین برندها و حتی مدل‌های مختلف متفاوت است. کد را دقیق ثبت کنید و از تعمیم جدول یک مدل به مدل دیگر خودداری کنید.

  • زمان بروز خطا؛ هنگام آب گرم یا گرمایش

برای تشخیص درست باید دفترچه و دستورالعمل همان مدل بررسی شود.

هماهنگی خدمات

برای بررسی امکان مراجعه در پرند، رباط‌کریم و شهریار، نام شهر و محله و مدل دستگاه را اعلام کنید. تشخیص نهایی و هزینه پس از بررسی و هماهنگی مشخص می‌شود.
